Authentication
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
    POST /api/auth/register                         // Register new user, hash password & return JWT
    POST /api/auth/login                            // Authenticate user & issue JWT
    POST /api/auth/logout                           // Invalidate token / server-side blacklist
    GET  /api/auth/me                               // Get current authenticated user profile

Orders & Kitchen Dashboard
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
	POST /api/orders/checkout                       // Validated for stock and open hours
	GET  /api/orders                                // All historical orders (Admin)
	GET  /api/orders/{id}
	GET  /api/orders/user/{id}                      // Order history for user
	GET  /api/orders/user/{id}/current              // Active order tracking for student UI
	GET  /api/orders/active                         // Kitchen active queue (FIFO)
	PUT  /api/orders/{id}/status                    // Advance status & record audit log
	POST /api/orders/{id}/cancel                    // Restricted cancellation guard
