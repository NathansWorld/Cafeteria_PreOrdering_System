1. AUTHENTICATION & SESSION MANAGEMENT (`/api/auth`)
========================================================================

[A] REGISTER A NEW USER (POST - Public)
- Endpoint: POST http://localhost:8080/api/auth/register
- DTO Mapping: RegisterRequestDTO -> AuthResponseDTO
- Curl (Git Bash / macOS / Linux):
curl -i -X POST http://localhost:8080/api/auth/register \
     -H "Content-Type: application/json" \
     -d "{\"firstName\":\"Charlie\",\"lastName\":\"Brown\",\"email\":\"charlie@campus.edu\",\"password\":\"securepassword123\"}"

- Curl (Windows CMD):
curl -i -X POST http://localhost:8080/api/auth/register -H "Content-Type: application/json" -d "{\"firstName\":\"Charlie\",\"lastName\":\"Brown\",\"email\":\"charlie@campus.edu\",\"password\":\"securepassword123\"}"

- Curl (Windows PowerShell):
curl.exe --% -i -X POST "http://localhost:8080/api/auth/register" -H "Content-Type: application/json" -d "{\"firstName\":\"Charlie\",\"lastName\":\"Brown\",\"email\":\"charlie@campus.edu\",\"password\":\"securepassword123\"}"

- Expected JSON Response (201 CREATED):
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "tokenType": "Bearer"
}
